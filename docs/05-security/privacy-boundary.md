# 隐私边界（Privacy Boundary）

本文是 [原则与边界](../00-overview/principles-and-boundaries.md) 在隐私与数据处理方面的具体说明。

## 数据不出设备

- 流量处理全部在设备本机完成，不经过任何外部代理或服务器，也不上传业务流量。
- 本地 SOCKS5 中继仅监听本机随机端口，使用每次启动生成的随机凭据，不对外暴露。
- 出站 Socket 先经 `VpnService.protect()`，不回环进 TUN。

## 不解密、不修改内容

- Pakomo 不进行 TLS 中间人解密，不持有证书，不解密 Payload。
- 默认不修改、不注入应用层内容，不改写响应正文，不伪造成功应答。
- 因此应用层内容故障属于明确不做的范围，参见 [限制](../01-capabilities/limitations.md)。

## 不读取、不保存 Payload

日志与统计不记录 DNS 报文正文、HTTP 内容、Cookie、凭据以及其他应用数据。

- 逐连接流量记录只记录连接元数据，包括协议、主机、端口、上下行字节数、是否暂扣或整形，以及状态，不记录内容。
- 故障命中日志只记录动作名与归属，不记录报文正文；同一连接的重复包去重，重连风暴按秒汇总限速。
- 诊断页的 Logcat 为应用自身的日志输出，不含被测 Payload。

## 权限用途

各权限的用途逐条列于 [原则与边界](../00-overview/principles-and-boundaries.md) 第 3 节。其中 `QUERY_ALL_PACKAGES`
仅用于在接管范围内选择已安装应用，`VpnService` 仅用于本机转发，不建立到外部的隧道。

## 授权使用

Pakomo 是网络测试工具，仅限在具备测试授权的网络与应用上用于测试、研究与学习，不得用于未经授权的流量拦截或干扰。
