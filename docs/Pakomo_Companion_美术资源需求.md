# Pakomo · 看板娘 Pako 美术资源需求

> 面向美术的资源清单。Pakomo 是一款 Android 弱网模拟工具;Companion(看板娘)主题在不改变工具布局的前提下,用角色 Pako 增加品牌与情绪。本文件列出全部需要的图。
> 工程侧接入:每张图放进 `res/drawable`,按下方命名;代码只按名字取图,不改布局。

---

## 0. 角色设定 · Pako

- 浅**灰蓝**长发、**青碧色**眼睛、白/浅蓝**露肩针织**;头侧别着一只**小黑蛙**发饰(黑色小兽,是品牌记忆点)。
- 常见动作:手心托举一枚**发光的青色数据方块**。
- 气质:轻二次元、干净、克制;不是游戏 HUD 风,不堆科技特效。

**配色参考(取自角色/图标真实采样):**

| 用途 | 色值 |
|---|---|
| 发色(灰蓝) | `#5883B3` / `#6D9AC7` |
| 发丝高光(浅青) | `#B2E1EE` |
| 眼睛 / 数据方块(亮青) | `#5FD0DE` 一带 |
| 腮红 / 肤色粉 | `#F2C5C6` |
| 小黑兽发饰 | `#2A2A2E`(近黑) |
| 全息碎裂点缀(粉) | `#E6B8D0` |
| 主题强调色(界面用) | `#4A72A8`(灰蓝) |
| 界面背景(暖中性灰) | `#F3F2EF` |

> 界面是**暖中性灰底**,不是纯白也不是蓝紫。角色是冷色身份,靠暖灰底衬托。

## 1. 通用技术要求(所有图)

- **背景透明**(PNG 或 WebP 带 alpha)。
- **不要在图里烘焙任何文字**(标题/说明都是代码渲染)。
- 主体留安全内边距,勿贴边(除非该图明确要求"贴底/满构图")。
- 优先 **WebP**;按密度桶提供(mdpi–xxxhdpi),或给一张 **xxhdpi 高清**由系统降采样。
- 命名全小写下划线,严格按下方给的资源名。

## 2. 批次 B · 空状态角色(3 张) — 最好画,建议先出

出现在"空/无内容"的页面,底色是浅灰,**无背景适配难题**。居中构图,约 **1:1**(如 480×480 @xxhdpi),透明。

| 编号 | 资源名 | 出现位置 | 表现 |
|---|---|---|---|
| B1 | `empty_apps` | 选择应用时搜不到结果 | Pako 摊手/无奈 |
| B2 | `empty_address` | 指定地址列表为空 | Pako 抱着空的数据盒 |
| B3 | `empty_targets` | 特殊故障目标页没有可选目标 | Pako 指向(提示先去选目标) |

*(B4 `empty_logs`「Pako 看着空终端」为可选,日志空态较少见,以后再补。)*

---

## 3. 批次 A · 状态卡角色(5 张)

出现在首页顶部的**状态卡右侧**。是**局部裁切**(脸 + 肩 + 托举数据方块那只手),**不是全身**。横向约 **3:2**(如 312×208 @xxhdpi),透明。

| 编号 | 资源名 | 对应状态 | 表现 |
|---|---|---|---|
| A1 | `mascot_status_running` | 运行中 | 托举发光青色数据方块,自信/微笑 |
| A2 | `mascot_status_idle` | 空闲运行(已开但没选目标) | 提示/指向,像在催"快选目标" |
| A3 | `mascot_status_starting` | 正在启动 | 观察/等待 |
| A4 | `mascot_status_stopped` | 已停止 | 安静/休息(可略降饱和) |
| A5 | `mascot_status_error` | 启动失败 | 困惑 + 一枚轻微错位的碎块 |

### ⚠️ 关键难点:背景适配

状态卡的**底色随状态变化(实色)**:运行=**蓝**、空闲=**橙**、停止=**灰**、启动/失败=**浅底**。所以 A 系列角色要能压得住这些底:

- 主体带**描边 / 柔和轮廓光**,保证在**深色实底**和**浅底**上都读得出;
- **避免大面积纯白**(浅底会消失)或**大面积纯黑**(深底会消失);
- **左侧 55–60% 留空/透明**——那里要压状态文字,角色只占右侧。

若某些高饱和态(尤其运行蓝)实测压不住,可只在低饱和态出角色,高饱和态回退(工程侧兜底)。

## 4. 批次 C · 首页角色主卡(C1,差分方案)

首页下方一整块区域(接管范围卡下方 → App 底部)是角色的主舞台,横向铺满。规则/日志/设置三行导航**浮在角色之上**,靠图的**左上留白**避让。

**难点:这片区域高度随状态变**(全局/指定 × 停止/运行,约 **394–554dp**)。不用一张图硬拉伸(会变形),改用**差分变体 + 按尺寸分档 + 随机**:

### 分档(按区域高度,宽高比 ≈ 对应状态区域)

| 档位 | 资源名 | 对应状态(区域高度) | 相对形态 |
|---|---|---|---|
| tall | `mascot_home_tall_1..n` | 停止态(最高) | 更竖,人物更完整(大半身/全身) |
| mid | `mascot_home_mid_1..n` | 运行 或 指定停止(中) | 中等 |
| short | `mascot_home_short_1..n` | 指定 + 运行(最矮) | 更扁,人物集中下部(半身/局部) |

### 每档多张差分

- 每档出 **3–5 张差分**(不同姿势/表情/小动作),**做多点没事**。
- 切换状态时,工程侧按当前区域高度选到对应档,再在该档里**随机取一张**显示。

### C1 通用约束

- 透明背景;
- **主体贴底**(角色站/坐在 App 底边上)、**横向满构图**(填满宽度);
- **左上留白 / 透明**,给规则、日志、设置三行导航文字避让;
- 每档的宽高比尽量贴近该状态区域的宽高比,减少裁切。

## 5. 命名与交付汇总

```
res/drawable/
├─ empty_apps
├─ empty_address
├─ empty_targets
├─ mascot_status_running
├─ mascot_status_idle
├─ mascot_status_starting
├─ mascot_status_stopped
├─ mascot_status_error
├─ mascot_home_tall_1 … _n
├─ mascot_home_mid_1  … _n
└─ mascot_home_short_1… _n
```

**建议出图顺序:B(3 张,最省事) → A(5 张,需背景适配) → C1(分档 × 差分,最费)。**

出好任意一批丢给工程侧即可接入(改两个取图函数,调用点不动)。
