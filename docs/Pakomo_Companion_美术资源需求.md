# Pakomo · 看板娘 Pako 美术资源需求

> 面向美术的资源清单。Pakomo 是一款 Android 弱网模拟工具;Companion(看板娘)主题在不改变工具布局的前提下,用角色 Pako 增加品牌与情绪。本文件列出全部需要的图。
> 工程侧接入:每张图放进 `res/drawable`,按下方命名;代码只按名字取图,不改布局。

---

## 0. 角色设定 · Pako

- 浅**灰蓝**长发、**青碧色**眼睛、白/浅蓝**露肩针织**;头侧别着一只**小黑蛙**发饰(黑色小兽,是品牌记忆点)。
- 常见动作:手心托举一枚**发光的青色数据方块**。
- 气质:轻二次元、干净、克制;不是游戏 HUD 风,不堆科技特效。

**配色参考(取自角色/图标真实采样):**

| 用途 | 色值 |
|---|---|
| 发色(灰蓝) | `#5883B3` / `#6D9AC7` |
| 发丝高光(浅青) | `#B2E1EE` |
| 眼睛 / 数据方块(亮青) | `#5FD0DE` 一带 |
| 腮红 / 肤色粉 | `#F2C5C6` |
| 小黑兽发饰 | `#2A2A2E`(近黑) |
| 全息碎裂点缀(粉) | `#E6B8D0` |
| 主题强调色(界面用) | `#4A72A8`(灰蓝) |
| 界面背景(暖中性灰) | `#F3F2EF` |

> 界面是**暖中性灰底**,不是纯白也不是蓝紫。角色是冷色身份,靠暖灰底衬托。

## 1. 通用技术要求(所有图)

- **背景透明**(PNG 或 WebP 带 alpha)。
- **不要在图里烘焙任何文字**(标题/说明都是代码渲染)。
- 主体留安全内边距,勿贴边(除非该图明确要求"贴底/满构图")。
- 优先 **WebP**;按密度桶提供(mdpi–xxxhdpi),或给一张 **xxhdpi 高清**由系统降采样。
- 命名全小写下划线,严格按下方给的资源名。

---

## 2. 批次 B · 空状态角色(3 张) — 最好画,建议先出

出现在"空/无内容"的页面,底色是浅灰,**无背景适配难题**。居中构图,约 **1:1**(如 480×480 @xxhdpi),透明。

| 编号 | 资源名 | 出现位置 | 表现 |
|---|---|---|---|
| B1 | `empty_apps` | 选择应用时搜不到结果 | Pako 摊手/无奈 |
| B2 | `empty_address` | 指定地址列表为空 | Pako 抱着空的数据盒 |
| B3 | `empty_targets` | 特殊故障目标页没有可选目标 | Pako 指向(提示先去选目标) |

*(B4 `empty_logs`「Pako 看着空终端」为可选,日志空态较少见,以后再补。)*

---

## 3. 状态卡装饰(无需出图)

> 首页顶部状态卡右侧**不放角色形象**——一屏两处角色就不"轻"了。这里改为一组随 VPN 状态点亮/熄灭/错位的**抽象数据块装饰**(呼应品牌"数据方块"母题),由**工程侧纯绘制**,**不需要美术出图**。角色形象集中放在首页底部主卡(下一节 C1)一处。

---

## 4. 批次 C · 首页角色主卡(C1,差分方案) — 唯一的角色形象位

首页下方一整块区域(接管范围卡下方 → App 底部)是角色的主舞台,横向铺满。规则/日志/设置三行导航**浮在角色之上**,靠图的**左上留白**避让。

这片区域高度随状态变(全局/指定 × 停止/运行),但**统一按"最小档"一个尺寸出图**——不分档:图**满宽、贴底**、比例约 **0.95(宽 ÷ 高,即略高于正方)**;区域比这大时,角色照旧那么大贴在底边,**上方自然留空**。这样一种尺寸就通吃所有状态,美术只做一套。

### 差分变体(多张随机)

| 资源名 | 数量 | 说明 |
|---|---|---|
| `mascot_home_1 … _n` | **3–5 张(做多点没事)** | 同一尺寸/比例的差分(不同姿势/表情/小动作);切换状态时工程侧**随机取一张**显示 |

### C1 通用约束

- 透明背景;
- **主体贴底**(角色站/坐在 App 底边上)、**横向满构图**(填满宽度)、比例约 **0.95**;
- **左上留白 / 透明**,给规则、日志、设置三行导航文字避让;
- 主体集中在**下部**(大状态下上方会留空,别把关键内容放太靠上)。

## 5. 命名与资源清单

```
res/drawable/
├─ empty_apps
├─ empty_address
├─ empty_targets
└─ mascot_home_1 … _n   (同一尺寸的差分,3–5 张)
```

**建议出图顺序:B(空状态 3 张,最省事) → C1(首页主卡,同尺寸差分几张)。**

*(状态卡装饰是工程侧纯绘制,不在出图清单内。)*

出好任意一批丢给工程侧即可接入(改取图函数,调用点不动)。
